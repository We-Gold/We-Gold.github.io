# weavergoldman.com

My personal website, built with Astro.

## Run it

```
npm install
npm run dev
```

The site runs at [localhost:3000](http://localhost:3000).

## Build

```
npm run build
npm run preview
```

The build goes to `dist/`.

## Deploy

Pushing to `master` builds and deploys the site through GitHub Actions.
