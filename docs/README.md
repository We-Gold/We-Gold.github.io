# Docs

Operational guides for this site — how to actually do recurring work, written
for future-me who has forgotten the details.

These are **not** planning docs. Design rationale, build status, and open
questions live in `plans/`.

## Weaver's Weekly

The weekly data science / ML problem series at `/weekly`.

- **[Authoring a week](weekly/authoring-a-week.md)** — the golden path, start
  to finish. This is the one to reopen every week.
- **[Composing images](weekly/composing-images.md)** — how the image DSL fits
  together, and the two rules you can't break.
- **[Extending the DSL](weekly/extending-the-dsl.md)** — one-off visuals, new
  reusable atoms, new layouts.
- **[Troubleshooting](weekly/troubleshooting.md)** — symptoms → causes, for
  the failure modes that already cost a day once.
- **[Reference](weekly/reference.md)** — frontmatter schema, design tokens,
  atom props, file map.
